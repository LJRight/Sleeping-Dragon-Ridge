# Mossfang Goblin V2 — 모델링 검토용

사용자의 2026-11-17 지시에 따라 리깅과 애니메이션을 제외하고 모델 형태를 다시 제작했다. 기존 Goblin 원본 및 Unity 프리팹을 교체하지 않는다.

## 파일

- `Mossfang_Goblin_V2.blend`: 재질, 편집 가능한 부위별 메시, 조명과 카메라를 포함한 원본.
- `Mossfang_Goblin_V2_Static.fbx`: 모델만 내보낸 정적 FBX.
- `Mossfang_Goblin_V2_Static.glb`: 기본 PBR 재질을 포함한 정적 모델.
- `previews/Hero.png`, `Face.png`, `Front.png`, `Back.png`: 실제 모델의 Blender 렌더링.
- `create_goblin_v2.py`: 재생성 스크립트. 실행 시 이 폴더의 동일 이름 산출물을 덮어쓴다.
- `report.json`: 내보내기 직전 실제 메시 집계.

## 변경한 형태

몸통과 팔다리, 머리 주요 볼륨을 voxel remesh로 결합하고 표면을 정리했다. 굽은 등, 넓은 어깨와 가는 하퇴, 전방으로 나온 얼굴을 구성했다. 큰 매부리코와 콧방울, 광대, 턱·입술, 눈꺼풀, 귀 안쪽 연골, 엄니, 흉터 및 귀걸이를 추가했다. 손가락·손톱·발가락을 구분했다.

겹친 철제 견갑과 테두리·리벳, 가죽 패널·봉제선·벨트 버클, 정강이 보호구, 주머니·이빨 장식, 도끼의 날과 손잡이 감개를 별도 형상으로 만들었다. 외부 다운로드 모델·이미지·모션을 사용하지 않았다.

## 용도와 제약

현재 53,095정점, 104,262삼각형, 메시 오브젝트 211개인 **형태 검토용 원본**이다. 모바일 게임용 최종 자산으로 최적화한 결과가 아니다. 표면 재구성 메시이므로 관절 변형용 토폴로지, UV 아틀라스, 리깅, 애니메이션, LOD를 만들지 않았다. 게임에 적용하기 전 사용자 형태 검토 후 리토폴로지·베이킹·메시 및 재질 정리가 필요하다.

Blender의 미세한 표면 범프는 절차적 셰이더 노드이며 FBX/GLB로 베이킹하지 않았다. 외부 뷰어의 조명·재질 표현은 렌더와 다를 수 있다. 원본에서 정확한 표면 표현을 확인할 수 있다. Blender 제작·내보내기와 렌더 검토를 수행했으며 Unity 플레이 및 실기기 성능은 검증하지 않았다.

## 재생성

저장소 루트에서:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python ArtSource/GoblinV2/create_goblin_v2.py
```
