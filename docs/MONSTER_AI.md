# 근접 몬스터 AI 프로토타입

2026-11-17. 승인 범위: 감지·추적·공격·복귀만 구현. 기존 Dummy Monster의 ServerMonsterMovement를 교체했으므로 별도 컴포넌트 추가 없이 적용된다. 기존 무작위 배회 대신 원점에서 대기한다. Blender 모델·리그·애니메이션 파일은 변경하지 않았다.

## 행동

- Idle: 0.2초마다 반경 8유닛 이내의 가장 가까운 살아 있는 플레이어 감지. 벽 너머 대상은 제외.
- Chasing: 선택한 대상을 초당 2유닛으로 직접 추적. 유효한 동안 대상 유지.
- Windup: 중심 거리 2유닛 이내에서 방향을 고정하고 0.65초 준비. 준비 중에는 이동·회전하지 않는다.
- 타격: 준비가 끝날 때 중심 거리 2.5유닛·전방 100도·시야를 다시 검사하여 선택한 대상에게 피해 10을 한 번 적용한다. 범위 밖으로 피하거나 벽 뒤로 이동하면 빗나간다.
- Recovery: 적중 여부와 관계없이 0.85초 대기 후 추적/공격 재개.
- Returning: 대상 사망·연결 해제·스폰 위치 기준 12유닛 이탈 시 원래 위치로 돌아간다. 몬스터 자체가 경계를 넘거나 3초간 추적 이동이 막혀도 복귀한다. 복귀 중 신규 타깃을 잡지 않는다.
- Dead: 체력 0이면 행동 중지. 기존처럼 오브젝트는 남는다.

모든 의사결정·이동·피해는 서버에서 실행한다. 위치·회전은 NetworkTransform, 행동 상태는 서버 쓰기 NetworkVariable로 공유한다. 클라이언트 HUD 체력 목록에 상태를 표시한다. 향후 모델 연결 시 CurrentState를 Animator 표현에 사용할 수 있다.

## 조절

Dummy Monster의 ServerMonsterMovement Inspector에서 감지·추적 한계·공격 거리·각도·피해·준비/회복 시간·속도를 조절한다. 거리 기준은 캐릭터 중심이다. 몬스터 반경과 플레이어 반경의 합보다 Attack Start Range가 너무 작으면 서로 충돌해서 공격 거리에 도달하지 못할 수 있다.

## 제한과 수동 확인

플레이 실행 검증은 하지 않았다. 두 계정으로 접근해 가까운 플레이어 선택, 추적, 준비 중 회피, 서버 체력 감소, 대상 사망/퇴장 시 복귀를 확인한다. 죽은 플레이어의 부활·몬스터 리스폰은 이번 범위에 없다.

현재는 평탄한 Prototype용 직선 이동이다. NavMesh·장애물 우회·낭떠러지 회피는 없으며, 복귀 경로 자체가 막히면 복귀 상태로 남을 수 있다. 시야 검사는 환경 콜라이더를 장애물로 취급하고 다른 캐릭터는 가림 대상에서 제외한다. 복귀 시 체력을 자동 회복하지 않는다. 모델 공격 애니메이션/시각적 공격 예고는 아직 연결하지 않았으며 HUD의 Windup 표시로 준비 상태를 구분한다.

기존 빌드본에는 이 코드가 포함되지 않으므로 빌드 테스트 시 서버와 클라이언트를 모두 새로 빌드해야 한다.
