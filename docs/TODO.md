```markdown
### TODO-000 · 작업 제목

**상태** 대기 · **선행 항목** 없음 · **등록일** YYYY-MM-DD

**목표** — 누가 어떤 행동을 하면 무엇이 달라져야 하는가?
**현재 상태와 근거** — 현재 동작, 재사용할 코드·데이터·문서 경로
**범위와 결정** — 이번에 바꿀 부분, 이미 합의한 내용, 필요한 사용자 판단
**착수 전 사용자 질문** — 이 번호를 지시받으면 사용자에게 직접 물어볼 구체적인 질문을 적는다. 선택이 필요한 경우 권장안과 이유를 함께 제시한다.

**구현할 일**

- [ ] 어느 진입점에서 어떤 데이터를 읽고, 누가 변경하고, 어디에 반영할지 적는다.
- [ ] 기존 사용자·데이터, 재시도·실패·동시 실행에 필요한 동작을 적는다.

**완료 기준** — 시작 조건 → 사용자 행동 → 관찰할 결과를 적는다.
**작업 기록** — 구현 후 변경 파일, 검증 환경·결과·증거 링크, 미검증 사항과 다음 항목을 적는다.
```
